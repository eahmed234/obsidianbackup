# Standing renderings and rulings

Recurring phrases and names, so that every ledger and note renders them the same way. Each line rests on a
page of the five books or on a ruling by the user; add to it rather than deciding again. Ledger and note
writers read this file first.

## Phrases

| Arabic | Render as | Basis |
| --- | --- | --- |
| لم يلق كيدا | "met no fighting" | glossed «أي حربا» at *Subul al-Hudā* 4:14. A note that uses the rendering footnotes 4:14 once. |

## Names as printed

A name is written as the page prints it. Where the print looks wrong, the ledger keeps the print, says so in
a `- note:` and lists it under `unsettled:`; it is corrected only by a ruling recorded here.

| Printed | Where | Ruling |
| --- | --- | --- |
| أبو عمرو (beside Ibn Ḥazm / Ibn Hishām) | *Subul* 4:15, 4:17 — elsewhere «أبو عمر» (4:176) | *awaiting the user's ruling*; until then write "Abū ʿAmr", as printed |
